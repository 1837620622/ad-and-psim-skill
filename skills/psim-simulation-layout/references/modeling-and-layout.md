# 原生建模与工程排版

## 先选对模型层级

明确要回答的是系统动态、芯片功能、开关应力、损耗还是热行为。平均模型可以用于相应控制问题，但不能据此验收高频纹波、器件尖峰、开关损耗或具体芯片引脚。独立数值程序是对照工具，不是原生 PSIM 求解。

指定 UC384x、UC385x 等芯片时，核对当前库中实际可用模型及其支持范围，检查电源、地、参考、振荡、采样、补偿、启动、限流和输出极性。若原生库缺少对应模型，先查可用的官方模型路线，说明实际达到的层级，不放一个文字框就声称芯片控制已实现。

## 校准元件再批量创建

使用本机帮助、原生示例和一次小电路保存/重开确认：

| 项目 | 必查内容 |
|---|---|
| 类型与字段 | 原生类型名、属性名、单位、参数表达式和有效值 |
| 端口与方向 | 首端口、端口顺序、控制端、旋转角、镜像、符号尺寸 |
| 定位 | POINT/PORTS/AREA 各自支持哪些元件，不把一种参数套给所有符号 |
| 显示文字 | 关联字段与索引、参数更新后的实际显示 |
| 保存 | 返回值、目标文件内容变化、重新打开后的元件和网络 |

本机 Python 示例明确有些元件只由首端口和 Direction 定位。多写第二、第三个坐标不保证拉长或移动其它端口。各类二极管、MOSFET、探头、电源、连接器分别校准，不能用一种符号的几何规则推断全部库。

类型、名称与索引同时确认。加入 TEXT、WIRE 等原生图形对象后，旧索引可能变化；更新参数前重新枚举。更新后读回真实参数，不根据磁盘上存在一个旧文件认定保存成功。

## 常规图面安排

先确定画布、图框和阅读顺序，再摆器件和接线：输入与输入保护、整流/PFC、母线、隔离变换、输出和负载形成明确主路；控制和反馈放在对应功率级下方或附近。

- 主通路尽量连续，减少上下折返和跨整图回线。不要为了分区强行拆断本来简单的功率主路。
- 芯片外围按振荡、采样、补偿、参考和驱动分别就近摆放。功率开关、栅极回路、吸收和电流采样相邻。
- 反馈从实际测量位置返回控制器。隔离两侧有明确回流；浮地副边采用合适的差分测量，检查电压探头和全局地是否意外跨接隔离。
- 相同通道采用一致方向、间距和标注位置。不能把所有阻容均匀铺成网格，或把芯片放在一边、外围散落其它区域。
- 导线使用实际参与求解的 WIRE 对象，正交连接、明确端点与连接点。几何线或文字不是电气元件。
- 使用简洁、含义明确的信号名；只在确有必要时用跨区标签。长跨区线、过多局部标号和重复的大标题都妨碍阅读。
- 位号、真实参数和单位统一字号。关联文字优先，参数更新后重新导出检查。禁止静态假标注盖住属性。

颜色遵循软件与参考习惯，分清功率与控制网络。不要仅凭颜色判断实际电气接口，也不要套用其它 EDA 软件的接线语义。

## 保存前的电气审阅

检查开关方向、体二极管、驱动极性、死区、续流路径、L/C 初值、源极/发射极回流、取样正负和保护动作。核对短接、悬空端、未定义参数以及电源与控制之间正确的接口。

参数变化后优先检查数量级、单位和表达式求值。对于很快失控或出现突变的波形，先排查电流路径被中断、电容被理想电压源强制短接、驱动重叠和控制极性，不先随意加阻尼或改积分参数。

## 相关范例

使用当前任务提供的真实 PSIM 完整窗口，观察功率路径、对应控制和反馈的排布，并区别真实窗口截图与纯绘图导出。公开仓库不附客户截图，本机副本须核对实际存在和使用范围；PFC/反激等范例不是所有拓扑的固定模板。

本机原生范例在 `examples`、`Python/Samples` 和 `Tutorials`。按当前拓扑选最相关示例，不把 Python 创建样例中的默认数值当作设计参数。
