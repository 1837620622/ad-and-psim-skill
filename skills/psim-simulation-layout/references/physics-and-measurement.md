# 物理量与测量

## 参数的四种身份

分开列：设计值、工程假设、模型输入、仿真测量；硬件实测再单列。输入电压范围、寄生参数、器件压降和 ESR 如果是假设，不要写成任务书要求或实测值。

开关和磁性元件至少核对本次指标涉及的：导通电阻、二极管压降/电阻、绕组铜阻、漏感、励磁电感、饱和和电容 ESR。具体要哪些看模型层级，但不能为了效率好看而隐藏已知损耗。

## 变压器折算

先读所选模型对每个 R、L 字段的定义：字段名写着 secondary 不代表它接受实际副边值。若字段规定折算到原边，设 `n = Np/Ns`：

```text
R_副边折算到原边 = n² × R_副边实际值
L_副边折算到原边 = n² × L_副边实际值
```

例如匝比 90:9、副边实际铜阻 0.035 Ω，折算到原边是 3.5 Ω。若字段本来就接受副边实际值，直接填 0.035 Ω，不要再折算一次。多绕组模型还要确认参照的是哪个绕组。

本机 `TF_1F_1` 的模型说明采用原边参照。新模型或新版本先用简单电路和解析关系确认，不要把这个结论推广到所有 PSIM 变压器。

铜损核对时电流和电阻用同一参照侧：副边实际电流配副边实际电阻，折算电流配折算电阻。漏感能量也一样，不要再乘一次匝比平方。

## 功率与效率

先定测量边界、功率方向和正负号：输入以向系统供能为正，输出以向负载供能为正。交流输入用瞬时 `v(t)i(t)` 的周期平均，不用电压均值乘电流均值。

```text
P_in  = ∫ v_in(t) i_in(t) dt / Δt
P_out = ∫ v_out(t) i_out(t) dt / Δt
ΔE_C  = C (V_end² − V_start²) / 2
ΔE_L  = L (I_end² − I_start²) / 2
P_残余 = P_in − P_out − ΔE_已知 / Δt
```

只有在稳态、方向一致、边界和损耗模型都合适时，`100 × P_out / P_in` 才叫效率；否则叫功率比。储能项不全时，残余功率不能全算作器件损耗。

效率超过 100%、残余功率符号反常或输入功率很小，先查方向、窗口、储能、变比和数据分辨率，不要截断到 100% 或删掉异常点。反向功率和再生工况单独说明。

理想模型接近 100% 不代表实物效率；功能级模型证明不了宽带噪声、全温度、EMI 或样机热性能。

## 测量工具

CSV 必须来自原生 Graph/SMV 或受控的 Simview 导出。先看表头、单位、编码和 Time 列，确认不是别的程序算出或重绘后的数据。

```text
python scripts/analyze_waveform.py native.csv --pin Pin --pout Pout --signal Vout --start 0.3 --end 0.4
python scripts/analyze_waveform.py native.csv --vin Vin --iin Iin --vout Vout --iout Iout \
    --fundamental-hz 50 --cycles 5 --end 0.5 --gate Gate --threshold 0.5
```

- `--time` 默认 Time，列名按真实表头写。功率列用 `--pin/--pout`，电压电流列用完整的 `--vin/--iin/--vout/--iout`，两种口径不能混用。
- `--capacitor Vbus=0.002`、`--inductor IL=0.001` 加入已确认参照侧的储能项，单位用 SI（F、H、V、A、s），不要写带工程后缀的字符串。
- 默认只报功率比；`--steady` 表示调用者已用相邻周期和储能确认了稳态，不是工具替你认证。
- 门极上升沿少于三个时只报"数据不足"。采样间隔标为输出间隔，不冒充求解步长。
- 均值和 RMS 按线性插值段精确积分，V/I 模式在同一段上算乘积积分。稀疏采样漏掉的尖峰和开关事件补不回来，仍要做步长和采样敏感性对照。

## PF、谐波与动态

总功率因数 = `P_in / (V_rms × I_rms)`，不能只拿基波相位余弦当总 PF。工具只在 V/I 模式、给了 `--ac-input` 和 `--fundamental-hz`、窗口为整周期时才输出 `input_total_power_factor`。THD 要写明基波、谐波阶数、是否去直流、窗口和频谱分辨率；FFT 的时间区间、输出间隔和 Nyquist 范围要与测量带宽相符。

阶跃要说明变化时刻、幅度、初态、观察窗口和测量定义。纹波取稳态；瞬态峰值和开关尖峰分开看；长时间包络代替不了开关细节。
