# 求解与时间基准

## 工况顺序

按任务选择启动、额定、输入范围、负载范围、必要的阶跃和参数敏感性。先确认额定工况下主回路和控制能工作，再扩展工况，避免带着一根接错的线跑完整个扫描。工况数量按任务定，不照搬以前项目的数量。

写清每个工况是从零初值启动，还是从哪份状态文件继续。状态文件要对应电路版本、参数、节点顺序和起始时刻；用原生保存/加载，不手改状态数值，也不要假设旧的 SSF 能用在改过的拓扑上。

本机原生 Python 示例用 `SaveFlag`、`LoadFlag` 传状态文件路径，用递增的 `TotalTime` 表示续算的**绝对**结束时刻。不要把每次延长的时长当成绝对时间，也不要把续算后的 Time 当成从零开始。

## 三个时间量分开记

| 时间量 | 证据 | 含义 |
| --- | --- | --- |
| 设定步长 | SIMCONTROL 或传入的求解参数 | 用户请求的值，不一定是实际采用值 |
| 实际步长 | 求解器信息、设置和核实过的采样机制，必要时用 Print Step=1 对照 | PSIM 可能采用比设定更小的步长 |
| 输出采样间隔 | 原始 Time 序列 | 还受 Print Step 影响，不等于内部步长 |

只有确认了均匀内部步长和输出机制，才能用"输出间隔 ÷ Print Step"推算内部步长，并写明这是推算。拿不到证据时写"输出间隔已测，内部步长待核实"。

例：本机一个反激阶跃个案设定 200 ns，实际采用 100 ns，Print Step=10 时 Time 间隔 1 µs。这只说明三者要分开记，不代表每个电路都会自动减半。

## 选步长并验证收敛

按需要分辨的最快事件（开关、死区、振荡、谐振）选步长，再做有针对性的减半对照。不能只按工频周期估精度，也不存在对所有应力测量都够用的"每周期若干点"。

在同一个稳定工况下比较实际开关频率、平均输出、纹波、峰值电流和电压。平均值稳定但尖峰、死区或门极频率随步长明显变化，说明这些量还没收敛。加大 Print Step 只让输出变稀，不提高求解精度。

频率从原生振荡器或门极波形测出。变频或跳脉冲控制要记录频率范围、周期分布和观察窗口；看开关细节时，输出采样也要足够密。

## 先确认稳态再统计

- 有工频输入时，看相邻完整工频周期的输出均值、RMS、母线能量和输入功率是否还在漂移。
- 直流或电机控制按对应的电周期、机械或控制时间尺度判断，不强行套 50 Hz 窗口。
- 输出看着平了但储能还在变：继续求解，或者把它当过渡过程单独报告。缩小纵轴、裁掉启动段、只看短窗口都不能证明稳态。
- 统计窗口取整周期并写明起止时间。非均匀采样用时间加权积分，不能直接对样本求算术平均。

## 记录与复算

记录模型和参数的哈希、求解器版本、初值或 SSF、绝对起止时刻、设定步长、实际步长证据、Print Time/Print Step、原始输出和统计窗口。只换负载或输入时，也要确认状态文件是否仍适用。

求解失败先读原生错误和参数，不要把别的程序算出的波形塞进结果目录。同一原因反复失败，就保留失败信息、修具体问题，不要无限重试或悄悄换成更容易通过的模型。
