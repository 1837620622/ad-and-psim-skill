# 求解、状态与时间基准

## 工况顺序

根据任务选择启动、额定、输入范围、负载范围、必要阶跃和参数敏感性。先确认额定回路及控制可工作，再扩展工况，避免同一根接错的线重复跑完整扫描。工况数量与文件组织服从任务，不固定为某个历史项目的数量。

明确每个工况从零初值启动，还是从哪份原生状态继续。状态文件要对应电路版本、参数、节点/状态顺序与起始时刻。使用原生保存/加载，不手改状态数值，不假定任意一份 SSF 都能用于修改后的拓扑。

本机原生 Python 例子通过 `SaveFlag`、`LoadFlag` 传入状态文件路径，并用递增的 `TotalTime` 表示后续绝对结束时刻。其它版本或接口先查相应帮助；不要把每次延长时长误填成绝对时间，也不要把续算后的 Time 当成重新从零开始。

## 三种时间量必须分开

| 时间量 | 证据 | 解释 |
|---|---|---|
| 设定积分步长 | SIMCONTROL 或传入求解参数 | 用户请求的值，不必然是实际采用值 |
| 实际求解步长 | 求解器信息、设置与已核实的采样机制，必要时 Print Step=1 对照 | PSIM 可能使用小于设定值的允许步长；要现场核对 |
| 输出采样间隔 | 原始 Time 序列 | 通常还受 Print Step 影响，不能直接等同内部步长 |

只有确认均匀内部步长与输出机制时，才用 `Δt_out / PrintStep` 推算内部步长，并把它表述为有前提的推算。无法取得内部步长证据时写“输出间隔已测，内部步长待核实”。

本机反激阶跃个案设定 200ns，实际采用 100ns，Print Step=10 时 Time 间隔 1µs。这说明必须分列三者，不代表每个电路都会自动减半。

## 选择步长并验证收敛

先按最快需分辨的开关、死区、振荡和谐振事件选择可行步长，再做有针对性的减半或逐步减小对照。不能只用工频周期估计高频开关电路的精度，也不能把某个“每周期若干点”当作所有应力测量都足够的保证。

比较同一稳定工况下的实际开关频率、平均输出、纹波、峰值电流与电压。若平均电压稳定而尖峰、死区或门极频率随步长明显变化，相关指标还未收敛。增加 Print Step 只改变输出稀疏程度，不等于提高求解精度。

频率从原生振荡器或门极数据测出。变频和跳脉冲控制应记录频率范围、周期分布及观察窗口，不能只报一个设定频率。观察开关细节时，足够密的输出采样同样必要。

## 确认稳态再统计

- 对有工频输入的变换器，检查相邻完整工频周期的输出均值、RMS、母线能量与输入功率是否继续漂移。
- 对直流或电机控制问题，按相应周期和机械/控制时间尺度判断；不要强迫所有模型用 50Hz 窗口。
- 输出看似平稳但储能仍变化时，继续求解或单独报告过渡状态。靠缩小纵轴、裁掉启动或只看短窗口不能建立稳态证据。
- 窗口端点取完整周期并说明时间范围。非均匀数据用时间加权积分；只对样本数量取算术均值可能偏置结果。

## 数据与复算记录

记录模型与参数哈希、求解版本、初值/SSF、绝对起止时刻、设定步长、实际步长证据、Print Time/Print Step、原始输出和统计窗口。仅更换负载或输入时也要核对状态是否仍适用。

仿真失败先读原生错误与参数，不把独立程序波形补进结果目录。重复失败且原因相同，应保留失败信息并修复具体问题，不无限重试或悄悄改成更容易通过的模型。
