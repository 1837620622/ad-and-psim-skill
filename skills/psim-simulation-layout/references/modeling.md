# 建模与元件校准

## 先选模型层级

先想清楚要回答什么：系统动态、芯片功能、开关应力、损耗还是热。平均模型适合控制问题，但不能用来验收高频纹波、器件尖峰、开关损耗或具体芯片引脚。用户自己的数值程序是对照工具，不是 PSIM 求解。

指定 UC384x、UC385x 等芯片时，查当前库里实际有没有这个模型、支持到什么程度，并检查电源、地、参考、振荡、采样、补偿、启动、限流和输出极性。库里没有就找官方模型路线，并写明实际达到的层级；放一个写着芯片名的文字框不算实现了芯片控制。

## 先校准，再批量建模

用本机帮助、原生示例和一个小电路的保存/重开确认：

| 项目 | 要查什么 |
| --- | --- |
| 类型与字段 | 原生类型名、属性名、单位、参数表达式和有效值 |
| 端口与方向 | 首端口、端口顺序、控制端、旋转、镜像、符号尺寸 |
| 定位 | POINT、PORTS、AREA 分别适用于哪些元件 |
| 显示文字 | 关联字段与索引，改参数后实际显示什么 |
| 保存 | 返回值、文件内容变化、重开后的元件和网络 |

有些元件只由首端口和 DIRECTION 定位，多写坐标不会拉长或移动其他端口。二极管、MOSFET、探头、电源、连接器要分别校准，不能用一种符号的几何推断整个库。

加入 TEXT、WIRE 等对象后旧索引可能变化，改参数前重新枚举。改完读回真实参数，不能因为磁盘上有个文件就认为保存成功。

本机原生示例在 `examples`、`Python/Samples` 和 `Tutorials`。挑和当前拓扑最接近的示例，不要把 Python 创建样例里的默认数值当设计参数。

## 保存前的电气审阅

检查开关方向、体二极管、驱动极性、死区、续流路径、L/C 初值、源极或发射极回流、采样正负和保护动作；再查短接、悬空端、未定义参数，以及功率和控制之间的接口。

参数改动后先看数量级、单位和表达式求值。波形很快失控或突变时，先查电流路径是否被切断、电容是否被理想电压源直接短接、驱动是否重叠、控制极性是否反了；不要先随手加阻尼或改积分参数。
