# 参考比例、功能布局与图面

## 把“像参考”落实为可比较的位置

先查看用户原图，不凭记忆套通用芯片版式。记录芯片轮廓、引脚行距、字号、左右引线长度、上下留白，以及供电、时钟、复位、调试接头的位置。画一个局部验证这些比例，再排整页。

| 检查项 | 方法 | 常见失败 |
|---|---|---|
| 芯片宽高 | 比较宽高比及它在局部区域中所占比例 | 芯片和空白放大、字体不变，显得空散 |
| 引脚行距 | 与实际名字和编号字高同时比较 | 长复用名挤到相邻行，或行距过大 |
| 外围符号尺寸 | 用同图芯片、引线和字号作参照 | 所有阻容使用过大的同一默认图形 |
| 关键锚点 | 归一化比较相对芯片的位置 | 元件种类相同，但晶振、电源和 JTAG 放错区域 |
| 局部连接 | 比较直接导线、共地和短线标号 | 参考中直接连接的外围被改成孤立标签堆 |
| 整页密度 | 查看全图和实际输出比例 | 把多页图平移拼接后靠巨大画布容纳 |

图像坐标 y 向下、AD 坐标常向上。需要脚本换算时先确认本机接口单位和方向，再使用明确的仿射变换。像素坐标只是位置草图；最后把热端和线端放在同一有效栅格，并原生核对。

调整几何比例时独立决定字体是否跟随。先看改变后的字高与引脚节距，不机械地把几何、线宽、字形一起缩到无法阅读。不要为每个元件临时设一套字号。

## 用户的 DSP 排列范例

- 当前任务中合法提供的排列参考，可用于观察窄长完整芯片、左侧电源与晶振、右侧短标号、下方调试接头和稳压电源。
- 原生局部导出用于核对图面密度、短线长度、错位去耦、电源与调试位置。公开仓库不附客户图片，本机副本须确认实际存在和使用范围后读取。

这些图片仅是布局范例，不能把 F28035、64 引脚、特定电阻值或电源安排强加到其它芯片。用户要求换芯片时重新依据封装和数据手册建符号。

此范例的关键是三只核心去耦电容错位贴近电源脚，晶振及两只电容就近直接接线，JTAG 和稳压器位于芯片下方，对外信号用短网络标号。不是照着黄色大矩形随意摆一圈元件。

## 普通工程图的整页安排

- 输入通常在左，输出在右；主功率路径优先在上，控制、反馈和辅助供电在相关位置。实际电路和参考图可以改变此方向。
- 按功能成组，不把阻容排成无意义矩阵。六路驱动可保持一致的通道结构，但各通道的去耦、栅阻和回路要局部完整。
- 留给长型号、数值和单位足够宽度。重复通道统一锚点、折线路径、字体和间距，避免一组松、一组挤。
- 跨区线长且无阅读帮助时用一致命名的短标号；局部必要连接直接画出。隔离两侧回流与边界明确，不用一个地符号掩盖隔离关系。
- 基本色遵循原生示例。若采用蓝导线、深色文字、浅黄芯片体，应保持整图一致；不把颜色本身当作电气类型或合格证据。

图框和图签服务定位与阅读，不做装饰面板。中文检查实际字体，不靠终端显示判断文件是否乱码。打印时检查实际字号，不能只在高倍缩放下觉得清楚。

## 何时必须改排而不是继续微调

如果芯片很大但文字很小、外围远离对应引脚、局部标签成堆、总图大块空白且阅读顺序断裂，回到功能布局和比例重新安排。不要继续叠加方框、标题、彩色背景来掩盖问题。

没有明确标准版本时，使用用户范例与官方工程惯例表述风格；任务要求特定 GB/T、IEC 或学校模板时核对相应原文。不能凭“看起来规范”宣称完成某项标准认证。
